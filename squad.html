位置推荐干员职责
突破手红狼 / 威龙走最前面开门探路，第一个跟敌人交火
奶妈蜂医 / 蝶 / 旅人（S11 新）跟在中间，负责救人回血，手里永远留着治疗技能
信息位露娜 / 回响 / 骇爪走在最后，用侦查箭/声波探测/数据飞刀提前发现敌人，指挥撤退路线
  • 只有两个人？突破手 + 奶妈是底线组合，能打能奶不会瞬间团灭。
  • 全员莽夫队：三个突击干员硬冲也行，但要约好"谁先倒谁别喊救命，等下一波"，避免三个人挤在一个点位一起蒸发。

开黑四条纪律（违反必吵架）

  1. 报点必须带方向和标志物。"有人有人有人"不算报点，那叫喊麦。
  2. 别抢奶。奶妈的治疗给先掉血的人，别因为谁残血谁先吃吵起来。
  3. 倒地不骂街。谁都有失误的时候，下一局再来。骂队友的队伍赢不了。
  4. 统一行动。要么一起冲，要么一起守，最怕一个人想撤一个人想打的"精神分裂局"。

新手报点速成

  1. 先用方位：以屏幕正前方为"12 点"，敌人在你右边就是"3 点方向"。
  2. 再加距离：近 / 中 / 远三档就够，不用精确到米。
  3. 最后加标志物："2 点方向、中距离、加油站门口"——队友一眼就能找到。
  4. 游戏内还有标记功能：看到敌人先标个点，再开口说话，效率翻倍。
