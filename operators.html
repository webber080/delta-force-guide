练干员的原则：优先练 2-3 名覆盖不同定位的主力（一个输出 + 一个奶妈 + 一个信息位），别雨露均沾。下面按兵种分类，难度星级越少越好上手。

突击位：冲在最前面的人

干员上手难度特点与适合谁
红狼低动力外骨骼 + 三联装手炮 + 烟雾弹，击杀回血、移速快。新手第一突击就练他
威龙中虎蹲炮 + 喷气推进 + 磁吸炸弹，技能组合度最高，喷气突进打高低差地图很秀
疾风中战术翻滚（缴械后约 1 秒掏枪真空期）+ 钻墙电刺 + 紧急回避锚点，机动拉扯型
无名中高静默潜袭 + 旋刃飞行器 + 闪光弹，渗透干扰流，单排残局能力强，需要意识支撑
说个常被搞混的：乌鲁鲁、比特属于工程位（不是突击位），银翼属于侦察位（不是突击位）——下面有分类。

支援位：全队的命都是你给的

干员上手难度特点与适合谁
蜂医低追踪激素枪 + 群体治疗烟（被激素枪命中可变绿烟）+ 烟幕无人机。开黑必备，新手友好
旅人 S11 新中战术猎犬"四叶"（侦查 + 撕咬牵制）+ 麻醉射击 + 治疗，本名罗温·沃尔什。支援位全能新答案，三旅人阵容"六打三"很离谱
蛊中"流荧"无人机群致盲恐惧 + 致盲毒雾 + 肾上腺素增益，阵地拉扯型辅助
蝶中快速修补（消耗自身护甲给队友补护甲）+ 变速烟雾 + 仿生蝴蝶群自动救援，本名莉娜·范德梅尔，S8 上线
说句实话：支援位看着不酷，但三人车队里最缺的就是奶妈。练好奶妈，全班开黑都得喊你上号。

侦察位：信息就是战斗力

干员上手难度特点与适合谁
露娜中侦查箭矢（标记掩体后敌人）+ 电击箭矢 + 增强型破片手雷，本名金卢娜。侦察位首练
骇爪高数据飞刀（骇入 10m 内电子设备致其失效）+ 闪光巡飞器 + 隐匿消声静步加速。操作上限高，进阶玩家玩具，本名麦晓雯
回响 S9 新中次声波干扰器 + 复合型闪光弹 + 回声探测器，被动感知 100m 内开火敌人并标记位置，专治老六
银翼中蜂鸟间谍摄像头（黏在敌人头盔上持续标记）+ 猎鹰仿生无人机（每秒标记视野内敌人）+ 脉冲手雷（让电子瞄具失效）

工程位：控场与防守专家

干员上手难度特点与适合谁
牧羊人低声波震慑无人机 + 声波陷阱 + 反相位声波减爆震，室内守点一绝，新手友好
深蓝中防爆套装（后方防护 + 防爆盾）+ 多功能钩爪枪 + 刀片刺网手雷，正面阵地的墙
乌鲁鲁低图像制导巡飞弹（可腰射预设制导）+ 速凝掩体 + 复合型燃烧弹，大范围爆炸封锁，分割战场很好用
比特中智能烟雾地雷 + 哨兵蜘蛛母巢（追踪爆炸 + 腐蚀），PVE 表现尤其强
液氮 S10 新中冰冻封锁 + 削弱载具，控场新解法，6-26 登场

新手推荐养成路线

  1. 第 1-2 周：红狼（突击）+ 蜂医（支援），两个都是低难度万金油。
  2. 第 3-4 周：加练露娜（侦察），学会用信息帮队友。
  3. 之后：根据自己喜欢的玩法补强——爱冲练威龙/疾风，爱阴人练骇爪，爱守点练牧羊人。
